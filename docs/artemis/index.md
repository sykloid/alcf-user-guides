# Artemis Overview

Artemis is ALCF's Kubernetes-based service infrastructure, allowing users to spin up and deploy persistent, long-lived, containerized applications which interoperate with ALCF production resources. This definition comes with several terms:

- **Kubernetes**: An industry-standard container orchestration platform (<https://kubernetes.io>).
- **Persistent/Long-Lived**: Applications which expect to be running at all times, servicing user requests (typically over HTTP).
- **Interoperation with ALCF Resources**: Applications running in Artemis clusters expect to be able to perform operations such as submitting jobs to the compute clusters, accessing data stored in shared filesystems, etc.
